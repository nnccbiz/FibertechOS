(סטטוס, BL, תאריך שחרור, ETA, תאריך אספקה) רשומים רק בשורה הראשונה של הקבוצה.

### שורות הסיכום (תחתית הגיליון)

- `Ordered quantity`: הכמות שהוזמנה מכל פריט.
- `delivered`: סכום המכולות.
- `to be delivered`: היתרה שעוד לא נשלחה.

## הערות למימוש

- תאריכים שמורים כמספרים סידוריים של Excel. למשל `46063` = 10.2.2026 ו-`46008` = 17.12.2025.
- בחלק ממספרי המכולות יש רווחים מיותרים (`"TCNU 1724048    "`). צריך לנרמל אותם לפני השוואה.
- הכמויות הן **במטרים** ולא ביחידות. לכן היתרה יכולה להיות שבר זעיר (0.013, 0.185…),
  שנוצר מהפרש בין אורך צינור שנמדד לאורך הנומינלי. אם מחליטים על ספי סבילות, צריך להביא את זה בחשבון.
